# Comic production notes

Lessons from Night Fare, Handover and Lost Property.

- **Hands:** check every hand at full size before publishing. Twisted fingers and hands that belong to the wrong person are the most common fault, as with the hands on the umbrella in Lost Property's slide 4. Prefer a shot with no hands when the story allows it.
- **Characters:** draw a model sheet first, then every panel from it. Give each character a fixed face, age and wardrobe.
- **Props:** the reference shows the state the panel needs. An open umbrella reference makes closed umbrellas open.
- **Object panels:** leave character-design wording out of the prompt, or faces appear in them.
- **Empty things:** the model fills them. Frame them out and let the caption say it.
- **Lettering:** all-caps comic lettering on paper-coloured boxes. Keep it off faces, and check each tail points at the speaker.
